## ⚙️ Local Setup

```bash
git clone https://github.com/devwhitewizard/nexus-v1md.git
cd nexus-v1md
npm install
cp .env.example .env   # fill in SUDO and SESSION_ID
npm start
```

---

## 📋 Environment Variables

| Variable | Required | Description |
|:---|:---:|:---|
| `SUDO` | ✅ | Your WhatsApp number with country code |
| `SESSION_ID` | ✅ | Session string (starts with `NEXUS~`) |
| `PREFIX` | ❌ | Command prefix (default `.`) |
| `MODE` | ❌ | `public` or `private` |
| `PAIRING_NUMBER` | ❌ | Phone number for pairing code login |
| `DATABASE_URL` | ❌ | PostgreSQL URL (falls back to SQLite) |
